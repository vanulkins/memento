# Результаты тестирования аудиофайлов

Методика, формат эталонного JSON и машиночитаемые результаты находятся в [`artifacts/test-results`](../artifacts/test-results/README.md).

Каждый результат строится сравнением вручную размеченного JSON с JSON аналитики, экспортированным из Memento после обработки того же MP3. UI, APK и видеодемонстрация в эту таблицу не входят.
