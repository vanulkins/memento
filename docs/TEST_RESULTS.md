# Методика и результаты тестирования

## Среда

- хост: Apple M4, 16 GB RAM, macOS 26.5.2;
- Android Emulator, Android 15, arm64;
- Memento 1.0.14;
- тестовое аудио: реальный пятиминутный русскоязычный диалог двух ведущих Easy Russian, 300 секунд;
- импорт выполнен через системный Android-пикер, а не прямой доступ к пути.

## Методика

Файл импортировали в приложение и дождались полного локального конвейера: декодирование, GigaAM, Nemotron, сохранение участников и облачное саммари. Затем приложение полностью остановили и открыли снова. Проверяли базу SQLite, экран саммари, стенограмму и соответствие персонажа стабильному `speaker_id`.

Это небольшой функциональный тест на одном русском аудио, а не полноценный сравнительный бенчмарк. Ошибки и границы реплик оценивались вручную. Сравнение скорости или точности с другими моделями не заявляется.

Дополнительно проверены сборка APK, установка поверх предыдущей версии, восстановление незавершённого задания саммари после перезапуска и полный декод видеодемонстрации без ошибок.

Для 1.0.14 отдельно повторён сценарий записи системного аудио: после остановки создано долговечное задание обработки, локально распознана речь, назначен «Коллега 1», сформированы саммари и краткое описание, а открытая страница встречи автоматически обновилась по событию завершения. Инструментальные Android-тесты завершились успешно; диагностический тест диаризации на внешнем трёхголосом fixture пропущен, поскольку сам fixture не публикуется в репозитории.
