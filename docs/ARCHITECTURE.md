# Архитектура решения

## Контекст

Memento обрабатывает аудио встречи на Android-устройстве. В облако отправляется только текст стенограммы и пользовательские вопросы; исходное аудио остаётся локально.

## Компоненты

1. **Android UI** — адаптированный интерфейс Memento внутри Android WebView и нативный Kotlin bridge.
2. **Audio pipeline** — запись микрофона и системного звука, импорт через Storage Access Framework, декодирование в mono PCM WAV 16 кГц.
3. **GigaAM v3 RNNT INT8** — локальное русскоязычное распознавание речи через ONNX Runtime.
4. **Nemotron 3 Sortformer diarization** — локальное распределение реплик по говорящим. Arrival-order cache сохраняет голосовые слоты между окнами, а сравнение центроидов устраняет дубли одного участника.
5. **SQLite** — встречи, реплики, временные метки, участники, саммари и история чатов.
6. **Фоновые сервисы Android** — запись, обработка, прогресс и уведомления.
7. **AI gateway** — HTTPS-сервис на Node.js за nginx. Он хранит ключ провайдера только на сервере и вызывает `deepseek-v4-pro` для саммари, метаданных и чатов.

## Основные технические решения

- ONNX Runtime Android выполняет локальный инференс без Python и серверной обработки аудио.
- Длинное аудио обрабатывается окнами, чтобы ограничивать использование памяти.
- Идентификатор говорящего стабилен для стенограммы и аватара.
- Незавершённые задания импорта и саммари сохраняются и продолжаются после перезапуска.
- AI gateway принимает задачи `summary`, `metadata`, `meeting_chat`, `knowledge_chat`.

## Безопасность и приватность

- ключ AI-провайдера отсутствует в APK;
- запрос включает install ID, timestamp, nonce, SHA-256 тела и HMAC-подпись;
- сервер проверяет допустимое отклонение времени, одноразовость nonce и rate limit;
- nginx принимает только HTTPS;
- секреты передаются через переменные окружения и не коммитятся;
- абсолютной защиты общего секрета внутри клиентского APK не существует — это описано в ограничениях.
