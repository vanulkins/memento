# Исходный код

- [`android`](android) — Android-клиент на Kotlin, локальные модели, SQLite, WebView UI и фоновые сервисы.
- [`server`](server) — Node.js AI gateway, конфигурация nginx и systemd unit.

Секреты в репозитории отсутствуют. Перед сборкой или развёртыванием заполните переменные из [`../config/example.env`](../config/example.env).
