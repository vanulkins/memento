# Видеодемонстрация

[`Memento-demo.mp4`](Memento-demo.mp4) — реальная запись Android-приложения: вход во встречу, вопрос в чате, ответ Memento, переход в стенограмму и прокрутка реплик.

Монтаж: 1920×1920, 60 fps, камера V4, матовые тапы и свайп, текстовый эффект Normal. Интерфейс в ролике не пересоздан — основой служит запись работающего приложения.
