# Memento

Memento — Android-приложение для локальной записи и импорта встреч, распознавания речи, диаризации собеседников, временных меток, экспорта стенограммы и работы с итогами встречи через защищённый AI gateway.

## Возможности

- запись микрофона и системного звука;
- импорт MP3, WAV, M4A и других форматов через системный Android-пикер;
- локальная расшифровка GigaAM без передачи аудио в интернет;
- локальная диаризация Nemotron с устойчивыми идентификаторами участников;
- стенограмма с временными метками и воспроизведением по реплике;
- участники, саммари, название и краткое описание встречи;
- чат по конкретной встрече и общая база знаний;
- экспорт стенограммы и аналитики;
- сохранение аудио и выбор аудиоустройств;
- фоновая обработка, прогресс и системные уведомления.

## Быстрый старт

1. Скачайте [`Memento.apk`](Memento.apk) или APK из GitHub Releases.
2. Разрешите установку приложений из браузера или файлового менеджера.
3. Установите APK на Android 8.0 или новее.
4. При первом запуске дождитесь загрузки моделей распознавания и диаризации.
5. Нажмите «Записать встречу» или выберите «Загрузить встречу».

Для записи системного звука Android покажет отдельное системное подтверждение. Облачные функции требуют интернета; запись, импорт, транскрипция и диаризация выполняются локально.

## Исходный код и сборка

- Android: [`src/android`](src/android)
- AI gateway: [`src/server`](src/server)
- переменные окружения: [`config/example.env`](config/example.env)

```bash
cd src/android
cp ../../config/example.env ../../.env
set -a && source ../../.env && set +a
gradle :app:assembleDebug
```

Требуются JDK 17, Android SDK 35 и Gradle 8.11+. Результат сборки: `src/android/app/build/outputs/apk/debug/app-debug.apk`.
